Module 01 - Setup

This README explains the difference between a repository, folder, file, commit, and push.

Repository:
A repository (repo) is a project container that holds all of your project's files, the full history of changes, and configuration like branches and access settings. A repository is hosted on GitHub and can be cloned to your local computer so you can work on the project offline.

Folder:
A folder (also called a directory) is an organizational unit inside a repository. Use folders to group related files (for example, Module01-Setup or Module02-Variables). Folders help keep the project structure clear and navigable.

File:
A file is a single document stored inside a folder (for example, a .cpp source file, a README.md, or an image). Files contain the actual code, text, or assets that make up your project.

Commit:
A commit is a recorded snapshot of one or more changes to files in your local repository. Each commit includes a message describing the change, the author, and a unique identifier (SHA). Commits let you track history and revert to previous states if needed.

Push:
Push is the operation that sends commits from your local repository to the remote repository on GitHub. After you commit locally, you push to share your changes with others and make them visible on GitHub.
